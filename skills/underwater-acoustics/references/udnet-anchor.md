Official Watermark V1 is the Reference Oracle for Python adapters. Call NOF/NCS Measurement-Driven Channel Replay, not synthetic generation. The original BELLHOP environment is underspecified, so label SIM-B a source-faithful reconstruction and preserve every reconstructed input.

Scope out SDRNet, modified DetNet, exact synchronization-offset reproduction, and unavailable author-recorded Nanpeng Island noise. Never substitute simulated noise for that At-Sea Measurement Experiment.
