# Underwater-acoustics Domain Profile

Apply this profile additively; core meanings and states stay unchanged. Read [the profile contract](references/profile.md). Require units and conventions for complex baseband signals, channel impulse responses, Doppler/time variation, OFDM framing, CSI quality, clipping, subcarrier count, SER, and complexity.

Distinguish Measurement-Driven Channel Replay, Propagation-Synthesized Channels, and At-Sea Measurement Experiments. A convenient substitute is not Source-Faithful Data. Use official reference implementations as Reference Oracles where available.

For the anchor paper, also read [udnet-anchor.md](references/udnet-anchor.md).
