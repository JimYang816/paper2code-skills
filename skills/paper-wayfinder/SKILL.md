# Paper wayfinding

Require an approved or actively reviewed Paper Dossier. Read [the GitHub graph rules](../paper2code-core/references/github-graph.md). Create one map issue that links the exact dossier revision, then child issues for `decision`, `research`, or `scientific-prototype` work. Preserve dependency order with native edges or the documented fallback.

Each child names its Evidence Items, completion artifact, acceptance condition, and return target. Issues coordinate work; resolved evidence and decisions are committed to the Scientific Record. Stop after mapping or reporting the next unblocked frontier item.
