# Isolate prototypes and preserve license boundaries

A Scientific Prototype lives outside production modules or on a temporary branch and answers one explicit decision question. Its conclusion may become an Evidence Item or Reconstruction Decision, but its code is not promoted directly: production work returns through the approved specification, ticket, TDD, and review path.

New workflow skills and code will be MIT licensed. Unchanged or adapted Matt Pocock skills retain their source, original license, content hash, and modification classification. The repository license does not relicense paper PDFs, Watermark, BELLHOP, other datasets, model artifacts, or third-party software; their identities and terms remain separate in Source and Dataset Manifests.
